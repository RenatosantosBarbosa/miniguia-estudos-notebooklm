# Miniguia de Educação Financeira com NotebookLM

## Contexto

Este projeto foi desenvolvido como parte de um desafio prático da DIO, utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi **educação financeira para iniciantes**, com o objetivo de reunir fontes abertas e confiáveis para estudar conceitos básicos relacionados à organização financeira e aos investimentos.

A proposta é utilizar a Inteligência Artificial não apenas para gerar respostas, mas também para auxiliar na compreensão, revisão e organização do conhecimento, sempre comparando as respostas com as fontes utilizadas.

## Objetivos

* Compreender como funciona um orçamento pessoal;
* Entender juros simples e juros compostos;
* Compreender o conceito de inflação e seu impacto no poder de compra;
* Entender a importância de uma reserva financeira;
* Conhecer conceitos básicos de investimentos e riscos;
* Testar diferentes formas de elaborar prompts no NotebookLM;
* Avaliar criticamente as respostas produzidas pela IA;
* Criar um miniguia de estudo que possa ser utilizado posteriormente para revisão.
